Amazon introduces TorchNeuron, an open-source tool that will allow developers to run code written in PyTorch on Amazon's Trainium chips with no rewrite (Todd Bishop/GeekWire)

Amazon's TorchNeuron software runs code written in PyTorch, the open-source framework used by many AI developers, on its Trainium chips after a basic configuration change. Amazon is opening it to all developers as a public beta and releasing it as open source.
